v0.4.0 scope

This release implements a deliberately scoped core: scientific calculator, unit conversion with dimensional checking, numerical calculus, descriptive statistics with OLS regression, eight probability distributions, core linear algebra, CSV data analysis, an X-Y SVG plot, three engineering calculators, live weather and currency, history and settings. See docs/BUILD_STATUS.md for exactly what is implemented vs. planned for later releases.

Scientific Calculator

Secure tokenizer → parser → AST → evaluator. No eval(). Supports + − × ÷ % ^, parentheses, factorial (!), C(n,r), P(n,r), standard functions, and the constants pi, e, euler.

Angle mode (radians/degrees/gradians) is set from the header selector and applies to sin, cos, tan, asin, acos, atan.

Unit Conversion & Dimensional Checking

One centralized unit registry (src/core/units.js). No UI component contains its own conversion formula.

Dimensional check

Try adding two quantities with incompatible dimensions (e.g. 5 m + 3 kg) to see DIMENSION_ERROR in action.
